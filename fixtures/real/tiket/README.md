# Fixture Nyata Tiket.com (fixtures/real/tiket/)

Direktori ini disiapkan untuk menampung data **asli** hasil unduhan dari extranet Tiket.com (TIX Hotel) client setelah dianonimkan (AGENTS.md aturan 1).

## Berkas yang Diperlukan:
1. **Ekspor CSV/Excel Reservasi (`csv/`)**:
   - Unduh dari: **TIX Hotel Extranet -> Reservasi / Booking List -> Export**
2. **Contoh Email Notifikasi Asli (`email/`)**:
   - Email konfirmasi booking baru
   - Email pembatalan / modifikasi

## Kebijakan Anonimisasi:
- Samarkan nama tamu dengan inisial.
- Hapus nomor telepon dan alamat email tamu.
- Pertahankan Order ID dan angka finansial.
