# Fixture Nyata Traveloka (fixtures/real/traveloka/)

Direktori ini disiapkan untuk menampung data **asli** hasil unduhan dari Traveloka TERA (Traveloka Extranet) client setelah dianonimkan (AGENTS.md aturan 1).

## Berkas yang Diperlukan:
1. **Ekspor CSV/Excel Reservasi (`csv/`)**:
   - Unduh dari: **TERA Extranet -> Booking List / Laporan Reservasi -> Export**
2. **Contoh Email Notifikasi Asli (`email/`)**:
   - Email Booking Voucher baru
   - Email Pembatalan Reservasi

## Kebijakan Anonimisasi:
- Samarkan nama tamu dengan inisial.
- Hapus nomor kontak pribadi tamu.
- Pertahankan Booking ID dan angka finansial.
